# 1. Concept

## 1.1 Incidents

Menace potentielle pour la sécurité des données que les administrateurs du SOC identifient et corrigent. Plusieurs déclencheurs d'incidents sont possibles, notamment :

  * Alertes SIEM
  * Alertes par courrier électronique
  * Alertes de sécurité provenant de services tiers, tels que SIEM, boîtes mail, données au format CSV ou de l'API RESTful Cortex XSOAR

Cortex XSOAR inclut plusieurs types d'incidents prêts à l'emploi et les utilisateurs peuvent ajouter des types d'incidents personnalisés avec des champs personnalisés, si nécessaire.
